## O projektu
ForgeAim je dedikovaný tréninkový software zaměřený na rozvoj svalové paměti, zkrácení reakční doby a zdokonalení přesnosti (aimu) pro hráče kompetitivních FPS stříleček. Projekt se inspiruje zavedenými platformami jako Aim Labs nebo KovaaK's a klade důraz na minimalistické prostředí s maximálním výkonem.
